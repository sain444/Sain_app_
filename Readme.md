# Messenger Sainn

Sainn is a modern messaging and communication application designed to bring people closer through simple, private, and reliable communication.

## Features

- 💬 Real-time messaging
- 🖼️ Image and video sharing
- 📁 File sharing
- 🎤 Voice messages
- 📞 Audio calls
- 🎥 Video calls
- 👥 Group conversations
- 📖 Stories / Updates
- 😀 Emoji support
- 🔒 Privacy settings
- 🚫 Block and report
- ✓ Read receipts
- ❤️ Message reactions
- ✏️ Message editing
- 🗑️ Message deletion
- 🌙 Dark and light themes
- 📡 Offline communication foundation

## Project Structure

- `apps/server` — Sainn backend
- `apps/mobile` — Sainn mobile application
- `infra` — infrastructure configuration
- `legal` — legal and privacy documents
